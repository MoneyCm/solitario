# Solitario

Solitario Klondike para el teléfono. Cada partida que reparte tiene solución.

Ábrelo en Chrome desde el celular y toca **Instalar** (o menú ⋮ → *Instalar app*). Después funciona sin internet.

## APK para Android

Descarga la última versión: https://github.com/MoneyCm/solitario/releases/latest/download/Solitario.apk
